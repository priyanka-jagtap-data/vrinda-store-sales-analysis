# Vrinda Store Sales Analysis

## Project Overview

This project analyzes Vrinda Store's 2022 retail sales data using Microsoft Excel. Is t exploresales performance, customer demographics, order status, and sales distribution across channels and states.

## Business Objectives

- Analyze sales trends across months.
- Compare sales by gender and age group.
- Identify high-performing sales channels.
- Identify states contributing the most sales.
- Examine order fulfillment and non-delivered order statuses.
- Develop data-driven recommendations for business improvement.

## Tools Used

- Microsoft Excel
- Pivot Tables and Pivot Charts
- Excel formulas
- Data cleaning and validation
- Data visualization

## Dataset

The workbook contains retail transaction data with fields such as order ID, customer ID, gender, age, order date, order status, sales channel, product category, quantity, amount, and shipping location.

## Analysis Performed

- Customer demographic analysis
- Monthly sales analysis
- Sales channel comparison
- State-wise sales analysis
- Order status analysis
- Gender and age-group comparisons
